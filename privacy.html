FamilyWall privacy policy

Last updated: October 23, 2026

FamilyWall is a personal, non-commercial wall-calendar app used by a single household on its own display. It is not distributed to the public.

What data it accesses

With the household's permission, FamilyWall uses the Google Calendar API to read, create, change and delete events on the calendars that the household's Google account can access, so they can be shown and edited on the wall display. It requests no other Google data.

Where data is stored

Calendar data is cached only on the household's own display, together with chores, lists and meal plans entered on it. FamilyWall has no servers. Nothing is sent to the developer or any third party; the display communicates only with Google's Calendar service.

Sharing

FamilyWall does not sell, share or transfer any data. It does not use data for advertising or analytics.

Google API Services User Data Policy

FamilyWall's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Data cached on the display is deleted when the app is removed or its data is cleared.
